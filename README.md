# Інтерактивний урок з інформатики (10 клас)
## Тема: Цифрова репутація, цифровий «слід» та принципи цифрового громадянства

### Опис проєкту
Інтерактивний навчальний вебзастосунок для проведення уроку інформатики у 10 класі.

### Інструкція з публікації на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub.
2. Завантажте файл `index.html` у гілку `main`.
3. Відкрийте **Settings → Pages → Build and deployment**, оберіть `Deploy from a branch`, гілку `main` та папку `/ (root)`.
4. Збережіть налаштування — через 1–2 хвилини урок буде доступний за вебпосиланням для класу.
